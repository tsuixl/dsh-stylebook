## 必须保留的五项用户修订

1. 移除右侧「实时预览」整栏，收拢成导航和设置内容两栏；窄屏也不再显示预览入口。
2. 字号输入数字为 `16px`、常规字重 `400`，保留 `px` 单位，移除可见上下箭头按钮。
3. 字重菜单使用 `Regular`、`Medium`、`SemiBold`、`Bold`，对应 `400/500/600/700`。`Mono` 是字体类别，不作为字重。
4. 外观方案与字重使用相同风格的自定义圆角菜单，不能替换成操作系统原生 select 弹层。
5. 字体搜索框的蓝色焦点边框位于圆角外层，内层输入框不出现方形蓝色描边。

保留字体区域内的简短文字和代码示例。它与用户删除的右侧实时预览栏不是同一个区域。

## 页面结构与视觉约束

```text
设置导航            外观
                    外观方案选择 / 已修改 / 另存为 / 删除用户方案
                    浅色 / 深色 / 跟随系统
                    界面文字：字体 / 字号 / 字重
                    代码字体：字体 / 字号 / 字重
                    简短文字与代码示例
                    配色：主题底色 / 侧边栏 / 强调色，右侧 HEX 胶囊
                    恢复默认 / 保存状态 / 完成
```

- 外观方案、主题模式、字体、配色分别使用一个圆角容器，标题与该组内容一起包裹。容器为 16px 圆角、1px 细边框、20px 内边距、16px 组间距，无阴影，背景跟随主题底色；≤620px 时内边距为 16px。
- 分组标题为 14px / 600；有说明的分组将说明放在标题下方，为 12px 次级色。字体组不再显示「界面与代码，分别设置」。组内字体行使用细线分隔；删除原有组间大分隔线。页面「外观」主标题、导航与底部操作栏保持现有结构。
- 保持浅色、深色两种状态下的颜色、留白、边框、圆角、图标尺寸及层级。
- 字体、方案、字重菜单以及另存为弹窗都是设计范围，不能只比较主页面。
- 字体区中「界面文字」「代码字体」各自单行排列：左侧角色名称，右侧字体选择、字号和字重；角色名称与配色名称统一为 14px / 500。移除重复的可见「字号」「字重」标题，保留每个控件的独立辅助标签。
- 三项颜色顺序：主题底色、侧边栏、强调色。主题底色统领主内容区、设置、浮层及派生表面；侧边栏同时用于左侧导航和右侧工具区。
- 颜色名称位于左侧，右侧为圆形色块与加粗 HEX 值组成的胶囊；HEX 字号固定 14px，焦点边框包住胶囊整组，内部输入框不单独出现方形描边。点击圆形色块仍调用取色器，HEX 可直接编辑。
- 配色在所有宽度均为单列：左侧名称、右侧胶囊；行高至少 54px，行间细分隔线，每行不再单独包裹卡片；整组三行位于同一个圆角分组中。
- 颜色名称使用 `14px`、字重 `500`；标题为「配色」，右侧不显示「浅色模式 / 深色模式」标签。明暗选择仍通过上方主题卡片操作，两套色板继续分别保存。
- 普通宽屏设置窗口最大宽度 `900px`，`≥1600px` 时为 `940px`；导航与内容分栏。
- 按 HTML 的 `930px`、`620px`、`440px` 断点调整边距和导航；字体行在 `≤760px` 时保留左侧角色名称和右侧字体选择在首行，字号与字重在右侧下一行等宽，避免挤压控件。
- 控件不得为容纳文字而随意缩小字号，也不得引入水平溢出。分组容器不使用 overflow:hidden 裁切菜单；字体和方案菜单保留现有固定定位浮层。
- 控件、菜单、弹窗、输入框与代码块均从主题底色派生，避免修改主题后内部仍固定白色。主体与侧栏各自计算前景、辅助文字和边框色；强调色用于交互重点及焦点。
- 实现使用的宿主组件只能作为构建材料，不能使其默认样式覆盖本设计要求。

## 功能与状态对照

| 界面 | 必须实现的状态和行为 |
| --- | --- |
| 方案菜单 | 内置方案、用户方案分组；当前选中；菜单外点击关闭；Escape、方向键、Home/End、Tab 行为。 |
| 主题卡片 | 三种选项、当前勾选、系统模式随系统变化；不在分区配色标题旁重复显示模式标签。 |
| 字体菜单 | 当前字体、搜索结果、手动输入项、系统默认；本机字体读取成功、拒绝、API 不支持。 |
| 字号 | 两个角色独立；整数 10–22；界面默认 14、代码默认 13；未完成输入不误保存。 |
| 字重 | 英文名称、对应字重效果、当前勾选、键盘选择。 |
| 色值 | 取色器与 HEX 同步、合法输入即时应用、无效输入回退、清空恢复单项默认、低对比度提示。 |
| 另存为 | 弹窗布局、输入焦点、空名/重名错误、24 长度限制、取消、保存成功和焦点回收。 |
| 方案修改 | 当前值变化显示「已修改」；另存后选中新方案；切换应用完整快照。 |
| 删除 | 仅用户方案显示删除按钮；删除后保留当前外观；不删除内置方案。 |
| 默认恢复 | 恢复默认主题、字体与颜色；不删除已保存用户方案。 |
| 保存 | 编辑即时生效；保存中、已保存、失败的状态必须与真实持久化结果一致。 |
| 关闭与重开 | 完成/关闭/Escape 关闭相应层级；重开保留已接受设置。 |

初始默认值、四套方案及色值定义位于 `src/model/defaults.ts`；派生颜色规则位于 `src/model/colors.ts`。`pnpm design:sync` 将 `src/model/browser.ts` 打包到 HTML 的标记区，两者使用相同定义及迁移规则；不要手工修改生成区。HTML 仍是界面和交互的设计基准。

## 演示环境与正式插件的边界

HTML 自带模拟 Harness 背景，便于查看设置页所处环境；生产中应使用真实宿主，不实现额外会话、文件树、账号或模型页面。原型顶部设计稿标识不进入正式插件。

原型使用浏览器 `localStorage`，键名为 `dsh-appearance-design-01`。该名称是既有演示存储键，第二版沿用它以保留用户试调数据，不表示仍是第一版。

正式插件使用 DSH Host 配置存储，保存成功显示「已保存」；HTML 初始显示「更改自动保存」，实际保存后显示「已保存到此浏览器」。这项演示与宿主的文案差异保留记录，最终设计对照时确认；不能以浏览器保存代替 Host 接受结果。

颜色配置版本为 2。旧版主内容区颜色迁移为主题底色，侧边栏和强调色保留；旧工具面板、输入框、代码块、设置与浮层颜色不再作为独立设置。迁移前的完整当前值和用户方案保留在 `legacyBackup`，供回退排查；未知版本、损坏数据和只读 Host 数据不自动写回。

真实字体列表取决于操作系统和权限。列表内容可以不同，菜单结构、控件样式、错误展示位置和交互不能另起一套。

参考截图是在保留用户试调设置的情况下生成的，包含 `#F2F2ED` 侧边栏和「已修改」标识；它不是原型默认配置。视觉比较必须先统一配置，不能把这类状态差异误判为实现问题。

## 本地查看

可直接用浏览器打开 [appearance.html](appearance.html)。这只是查看设计原型，不是部署 DSH Web 实例；当前插件验收在本机 DSH 桌面端进行，字体读取也以桌面应用中的实际结果为准。

如需通过 localhost 查看原型，可在仓库根目录运行以下可选命令：

```powershell
python -m http.server 8769 --bind 127.0.0.1 --directory docs/design
```

然后打开 <http://127.0.0.1:8769/appearance.html>。结束查看后在该终端按 Ctrl+C 停止服务。此命令只启动原型静态页面，不启动或修改真实 DSH。

浏览器可能已有演示存储。查看默认外观时使用页面的「恢复默认」；原型对照可使用独立浏览器上下文，避免覆盖日常试调数据。真实插件的视觉验收在桌面应用内执行，按 [桌面验收步骤](../development-plan.md#62-每轮桌面验收步骤) 记录并恢复测试前状态。

## 验收清单

每个界面改动都对照此清单，不以“功能类似”代替“与原型一致”。

- [ ] 同一窗口尺寸、同一字体环境、同一方案和同一明暗模式下，布局与视觉对齐。
- [ ] 桌面验收对照 `1495×884`、`823×884` 等实际可达到的内容尺寸，记录系统缩放和窗口最小尺寸限制；`390×844` 作为原型紧凑布局及后续 Web 验收参考，不因当前桌面无法达到该尺寸而要求另装 Web 实例。
- [ ] 主题卡片、字体/方案/字重菜单、另存为弹窗分别核对。
- [ ] 输入、悬停、选中、焦点、已修改和错误提示均对齐。
- [ ] 不存在右侧实时预览、窄屏预览入口、字号箭头或原生方案/字重 select。
- [ ] 字号输入数字为 16px，英文权重名称完整可读。
- [ ] 搜索框只有圆角外层焦点边框，没有内部方形描边。
- [ ] 全部原型功能使用真实数据/接口，演示 localStorage 不进入插件持久化路径。
- [ ] 真实 DSH 重启可恢复，禁用插件可撤销覆盖。
- [ ] 上游限制导致的差异有明确记录；未经确认的设计差异阻止发布。
